📌Undergraduate Innovation Project: Edge-Preserving Diffusion Models for Image Inpainting

Role: Core Member
Duration: Apr. 2025 – Present

🔍 Overview

This project aims to enhance diffusion-based image inpainting models for images with complex edge structures.
Conventional diffusion models often suffer from blurred boundaries and structural inconsistency in such scenarios.

To address this issue, we introduce a structure-guided framework that explicitly incorporates edge information into the diffusion process.

💡 Methodology

  • Edge Guidance
    Structural priors (e.g., Canny edge maps) are integrated into the network via a structure-aware attention mechanism.

  • Loss Function Design
    An edge-aware hybrid loss is designed, combining:

    • L1 reconstruction loss
    • VGG-based perceptual (feature matching) loss

  • Optimization Objective
    Improve both:

    • Pixel-level accuracy
    • Global structural consistency

🛠️ Contributions

  • Constructed and preprocessed the dataset
  • Reproduced baseline diffusion models
  • Designed and implemented model improvements
  • Performed training, hyperparameter tuning, and evaluation

📌 Industry Internship Project: Computer Vision at Nanjing TRS Information Technology Co., Ltd.

Role: Computer Vision Intern (Remote)
Duration: Jan. 2026 – Feb. 2026

📄 Download Internship Certificate (JPG)

🔍 Overview

This project focuses on the study and application of generative models in computer vision, particularly for image generation tasks.
We systematically explored the evolution and practical usage of models such as Autoregressive Models, Autoencoders, Variational Autoencoders (VAE), and Generative Adversarial Networks (GANs).

Based on the Stable Diffusion XL (SDXL) framework, we further investigated the roles of key components and their impact on generation quality.

💡 Methodology

  • Model Architecture Analysis
    Studied the core components of SDXL, including:

    • Text Encoder
    • Variational Autoencoder (VAE)

  • Fine-Tuning Strategy
    Applied LoRA (Low-Rank Adaptation) to adapt the model to different application scenarios.

  • Evaluation Protocol
    Conducted systematic evaluation of generated images in terms of:

    • Semantic consistency
    • Detail richness
    • Style adaptability

🛠️ Contributions

  • Investigated multiple generative model paradigms (AR, AE, VAE, GAN)
  • Analyzed key modules within the SDXL framework
  • Implemented LoRA-based fine-tuning experiments
  • Designed evaluation criteria and conducted comparative analysis
